# 🧪 Agnes Tachyon Interactive 3D Laboratory

> An immersive, interactive 3D isometric diorama web experience dedicated to **Agnes Tachyon** from *Uma Musume Pretty Derby*, built from scratch using **Three.js**, **HTML5**, and **Tailwind CSS**.

![Preview Banner](https://img.shields.io/badge/Status-Active-brightgreen) ![Three.js](https://img.shields.io/badge/Three.js-r128-blue) ![License](https://img.shields.io/badge/License-MIT-yellow)

---

## ✨ Features / Fitur Utama

- **Isometric 3D Diorama:** A meticulously crafted L-shape laboratory room modeled purely with Three.js primitives and custom geometries.
- **Architectural Typography:** Integrated 3D wall text spelling out **"AGNES TACHYON LAB"** spanning across the laboratory walls.
- **14+ Interactive Objects:** Every single piece of furniture and equipment in the room is interactive! Click on objects to inspect them.
- **Smooth Camera Animation:** Features a buttery-smooth linear interpolation (`lerp`) camera focus system that zooms into selected objects gracefully.
- **Glassmorphism UI Panels:** Clean, modern bottom-sheet info cards providing deep lore, character traits, and scientific trivia about Agnes Tachyon without blocking your view.
- **Dynamic Lighting & Shadows:** Soft directional sunlight streaming through windows, casting realistic shadows over custom teal-tiled floors.
